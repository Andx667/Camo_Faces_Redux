# Zeus Enhanced Compat (`cfr_compat_zen`)

Optional integration with [Zeus Enhanced](https://steamcommunity.com/sharedfiles/filedetails/?id=1779063631) (ZEN) — only active if ZEN is also loaded; otherwise this component does nothing.

Right-click a unit as Zeus to find **Camouflage** in the context menu:

- Selecting one unit lists its available camo patterns directly.
- Selecting several units at once offers **Apply Random Camouflage**, giving each one its own random pattern.
- **Remove Camouflage** appears whenever any selected unit currently has one applied.

Unlike the in-game dialog or ACE self-action, applying camo this way doesn't require the unit to be carrying a facepaint item or have its headgear off — Zeus sets it directly.

A CBA setting, **Enable Camouflage Context Actions** (on by default, under **Zeus Enhanced** in the settings menu), lets a curator turn this off individually — it only affects your own Zeus interface, not other curators or players.
